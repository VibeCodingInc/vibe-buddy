# Security Policy

## Reporting a Vulnerability

**Email:** security@slashvibe.dev

Please include a description, steps to reproduce, and potential impact.
We acknowledge within 48 hours and aim for a fix or mitigation plan within
7 days.

## Scope

This policy covers the Vibe Buddy application source in this repository and
the signed binaries published at
[VibeCodingInc/vibe-buddy-releases](https://github.com/VibeCodingInc/vibe-buddy-releases).
